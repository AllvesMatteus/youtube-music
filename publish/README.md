# 🚀 Ferramentas de Publicação & Releases

Este diretório contém o utilitário inteligente de build, versionamento e publicação automática de atualizações do **YouTube Music Desktop**.

📖 **Para um passo a passo detalhado com imagens e explicações, leia o nosso guia:**  
👉 **[COMO_USAR.md](./COMO_USAR.md)**

---

## 📁 Arquivos Desta Pasta

* **[`publish.ps1`](./publish.ps1)**: Script PowerShell inteligente de publicação.
* **[`publicar.bat`](./publicar.bat)**: Executável de 2 cliques para iniciar o processo.
* **[`.env`](./.env)**: Arquivo local com credenciais e chaves (protegido no `.gitignore`, nunca sobe para o Git).
* **[`COMO_USAR.md`](./COMO_USAR.md)**: Manual completo de como publicar e como funciona o auto-update.

---

## ⚡ Início Rápido

Dê 2 cliques no arquivo [`publicar.bat`](./publicar.bat) nesta pasta (ou no [`publicar.bat`](../publicar.bat) na raiz do projeto).
